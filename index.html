验收中心
分别验证系统工程与真实模型能力。
运行状态
工程验收
不调用模型。通过实际 HTTP 测试查询、创建、回查、取消与跨系统保存。会创建带“验收”标题的虚构需求和文档。
真实模型验收
使用当前 API，产生模型费用。运行 3 个固定任务：查询、创建测试需求、跨系统周报。点击后授权仅自动确认这些带本次验收标记的虚构记录；其他写入会拒绝。
验收报告检查真实调用和业务记录。周报完整事实准确性仍需人工复核，结果不能代表真实企业规模下的效果。
配置模型服务
默认仅保存于内存。可选择由 Windows 加密记住配置。
仅支持文本和工具调用。模型列表取决于账号权限，也可手动填写。
